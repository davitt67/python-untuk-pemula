# Python untuk Pemula

Repositori ini berisi hasil praktikum belajar dasar-dasar Python dari modul Santrikoding, lengkap dengan riwayat commit per tahap materi.

## Ringkasan Materi

1. **Dasar Pemrograman Python**: membuat dan menjalankan program pertama (`hello.py`).
2. **Variabel dan Tipe Data**: Numbers (integer, float), String, dan Boolean.
3. **Operator**: aritmatika, perbandingan (comparison), dan logika (`and`, `or`, `not`).
4. **Kondisional**: `if`, `elif`, dan `else`, serta pentingnya indentasi.
5. **Perulangan**: `for`, `while`, `break`, dan `continue`.
6. **Lists dan Dictionaries**: membuat, menambah, menghapus, menggabungkan item, dan mengakses/mengubah data key-value.
7. **Function**: arguments, arbitrary arguments (`*args`), keyword arguments, `**kwargs`, dan default value.
8. **Class dan Object**: membuat class, constructor `__init__`, method, dan parameter `self`.
9. **PIP**: mengecek versi, install, uninstall, dan melihat daftar package.
10. **Virtual Environments**: membuat, mengaktifkan, dan menonaktifkan venv.

## Struktur Folder

- `*.py`: contoh program tiap materi
- `screenshots/`: hasil eksekusi program dan perintah terminal

## Cara Menjalankan

1. Clone repositori ini dan masuk ke foldernya.
2. Buat dan aktifkan virtual environment:
   - Windows: `python -m venv venv` lalu `venv\Scripts\activate`
   - Mac/Linux: `python3 -m venv venv` lalu `source venv/bin/activate`
3. Install dependensi: `pip install -r requirements.txt`
4. Jalankan program, contoh: `python hello.py`

## Catatan

Riwayat commit mengikuti format `feat(topik): deskripsi` sehingga tiap tahap belajar terdokumentasi.
